# 大肥鱼控制台 · Fish Control

Windows 本机的小控制面板，目前只有两个开关：

- **大肥鱼是否启动**：启动或停止接话、模型调用和已授权的自主活动。停止保留 QQ/B站登录与历史，不强杀 QQ。已提交给平台的消息无法撤回。
- **是否开放聊天**：关闭时只有原主人能聊天；开启后，其他人也能通过 QQ 好友私信、所在群内 @、B站私信、评论回复和 @ 与她聊天。

本项目是现有 `D:\DeepSeekCompanion` 环境的增量控制器，不是完整 DSH 安装包。不要为了安装本面板重装账号或模型。

**当前验收状态**：启停及访客B站连续私信已验证。B站评论有发送回执但部分公开不可见，正在排查，不能保证评论/@最终展示。详细记录见 [HANDOFF.md](HANDOFF.md)。

## 在已配置的电脑上打开

双击 `启动大肥鱼控制台.cmd`，或 `Start-Fish-Control.ps1`。

浏览器地址：`http://127.0.0.1:17860`。关闭网页不会停止大肥鱼，要停止请按面板按钮。后台未运行时，启动按钮会调用原来的 `Start-Companion.ps1`。若 QQ 登录已失效，需要在 QQ/NapCat 完成登录。

默认保留原来的「已启动、仅与你聊天」。运行设置保存在大肥鱼自己的数据目录，重新打开面板不会重置开关。

## 本地安装／开发

需要 Node.js 22+；复用已有 Python、NapCat 和 DSH。控制面板本身没有 npm 依赖。

```powershell
node install.mjs
npm test
npm start
```

安装器针对交付时的 QQ host-v4、B站 dialogue-v2、autonomy-v3 做增量适配。先校验原代码，再在原项目的 backups 中备份，最后热加载配置。已安装时不重复覆盖。基线不符会停止，需由维护 AI 看清现有版本后调整。

## 开放模式的范围

- 不自动加好友、加群或修改平台隐私设置。仅处理平台接口能交付的消息；QQ 好友私信和群内明确 @ 才触发，不刷屏插话。
- 其他人的对话以平台、联系人、楼层/群分开，使用简短公开性格，不读取主人的固定会话、私人记忆或私人版人设。每个上下文保留最近 8 条消息，不创建新的 DSH 会话。
- 开放接话走 DSH 的官方模型调用与原费用保护，不能绕过累计 ¥40 上限或 2026-11-01 零点的暂停安排。
- 关闭开放会阻止新的访客回复；关闭期间的旧消息不会在重开后补发。发送结果不确定不自动重发。
- QQ/B站平台风控、登录失效和接口变更仍可能导致无法收发。轮询与模型处理需要时间，不是即时消息服务器。

## 隐私与维护

仓库不包含 API key、Cookie、令牌、聊天、私人版人设、运行状态或备份。程序只在 `127.0.0.1` 监听，写操作校验 Origin 和随机 CSRF token。

给另一个 AI 接手时，让它先读 [HANDOFF.md](HANDOFF.md) 和 [AGENTS.md](AGENTS.md)。完整私人交接资料继续留在原电脑，不要上传整个大肥鱼目录。
